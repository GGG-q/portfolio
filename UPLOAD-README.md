# GAO QI Portfolio — GitHub Upload

This folder contains the complete static portfolio website.

## Upload with GitHub Desktop

1. Extract the ZIP archive.
2. Open GitHub Desktop and clone `GGG-q/portfolio`.
3. Copy every item from this folder into the cloned repository root.
4. Commit the changes to `main` and push.
5. In GitHub, open Settings → Pages and publish from the `main` branch, root folder.

The repository root must contain `index.html`, `styles.css`, `script.js`, and the `images` folder.
